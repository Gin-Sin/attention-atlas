I

不是一条直线，而是三种瓶颈的分叉

一条路线减少 KV 头或每条记录的宽度；一条路线减少需要读取的位置； 另一条路线把整个历史折叠成固定状态。2025 年后的主流趋势是把这些路线重新混合。

KV 共享 / 低秩 稀疏 / 序列压缩 有限状态 混合架构
II

用“压缩发生在哪里”建立心智模型

不要只背缩写。先问被压缩的是头、每个 token、token 数量，还是全部历史状态。

Width / Heads

减少每条 KV 的宽度

MQA/GQA 减少 KV 头，MLA 把每个 token 的 KV 联合压到 latent。历史条目数仍随 L 增长。

Positions / Entries

减少读取或保存的位置

DSA 用 learned top-k 减少精读位置；CSA/HCA 先把多个 token 合成更短的历史。

State / Recurrence

不再保存逐 token 历史

Linear、DeltaNet、KDA 维护固定矩阵状态。成本不随历史增长，但信息会竞争有限容量。

III

十章课程

建议按时间顺序学习；已有 Transformer 基础时，也可从 MLA、DSA 或 KDA 直接切入。

证据层级与阅读约定

课程优先使用原论文、模型团队技术报告与官方开源实现；性能数字保留其适用边界。

Priority 01

正式论文 / 技术报告
